Radar and outreach workflow

Lead Flow Checklist

Use this flow on your Mac to move from cold websites to booked work using the radar and pitch generator.

Step 1 – Run the website radar
  1. Open Terminal.
  2. cd ~/opportunity-radar
  3. Update inputs/websites.csv with new websites you want to check.
  4. Run python3 website_radar/website_radar.py
  5. This creates a new CSV and JSON in outputs/ with scores for each site.
Step 2 – Generate outreach pitches
  1. In the same folder, run:
    python3 website_radar/generate_website_pitch.py
  2. It prints the path to a pitches_YYYY-MM-DD-XXXX.txt file in outputs/pitches/.
  3. Open it in TextEdit:
    open -a TextEdit outputs/pitches/pitches_...
  4. Each lead has a short summary and an email you can paste into Gmail.
Step 3 – Send outreach
  1. Copy the email for a lead from the pitches file.
  2. Paste into Gmail and edit anything you want to sound more like you.
  3. Send 5 to 10 good emails rather than a huge blast.
